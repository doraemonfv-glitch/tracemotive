# TraceMotive v0.4 review scorecard

Status: final scoring model. The score is a planning instrument, not a claim
that the implementation already passes.

## 1. Counting method

The supplied A-L review themes are deduplicated into 37 actionable units. A unit
is counted once even when several reviewers raised the same concern. The score
distinguishes:

- Material closure: an implementation and a verifiable test/gate are planned.
- Explicit safe decision: a feature is rejected or deferred with a reason,
  boundary, and release wording; this is a valid review response but not a
  material feature implementation.
- Open: no credible action or evidence yet.

The proposed Core target is at least 90% material closure. The plan currently
targets 34/37 Core material units (91.9%), one Conditional LangGraph unit, and
two intentionally non-material decisions: OTel export is deferred and
importance/confidence inference is explicitly rejected. If the LangGraph GO
gate passes, the material/conditional response reaches 36/38 (94.7%). Response
coverage is 37/37 because both decisions and the Conditional path are documented
and gated. This distinction prevents a deferral from being misreported as
shipped functionality.

## 3. Proposed result

| Measure | Numerator | Denominator | Result |

| Core material implementation target | 34 | 37 | 91.9% |
| Conditional LangGraph response if GO passes | 35 | 37 | 94.6% |

The Core material target is contingent on all Core P0 gates. LangGraph is not
counted as Core material unless C-V04-09 passes its full GO gate. If any issue or
support claim is removed, the score must be recomputed rather than silently
retained.

## 4. Reviewer-facing limitations

- This scorecard does not assert that Claude, Grok, or Manus each gave the same
  recommendation; the original reports are absent from the checkout.
- A planned issue is not evidence of completion. The release gate requires
  runtime logs, tests, artifact inspection, and documentation review.
- The current v0.3 evaluation numbers are not the review score. They measure a
  named private corpus and must remain corpus-specific.
- A safe rejection of OTel export and importance inference is a product-quality
  decision, not missing ambition. It prevents v0.4 from expanding into deferred
  or unsupported contracts.
